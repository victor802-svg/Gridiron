PHASE B1 — the probe (commit "cfb 1: feasibility")
=====================================================================

READ-ONLY against sources. One committed report,
docs/CFB_FEASIBILITY.md, answering with evidence, per the MLB
precedent:

1. SCHEDULE/RESULTS/STATS: does the ESPN core API carry the full
   FBS schedule, finals, and team game stats? Several past seasons
   reachable for walk-forward? How do FBS-vs-FCS games appear?
2. LINES: spread, moneyline, AND total (overUnder) coverage across
   a real current-week slate. What fraction of games carry each?
   (R-A makes this number the slate size.)
3. IDENTITY: if stats and lines both come from ESPN, the id space
   is single-source — confirm that, and the crosswalk problem
   disappears for CFB. If a second source is needed for anything,
   build the measured reference set per checklist item 3. Team
   names come from the feed's displayName, never typed (the K2
   rule).
4. MEASURED CONSTANTS: from past seasons, compute CFB margin SD
   and CFB total-points SD, dated, with N. Expect margin SD well
   above NFL's 12.70 — report what the data says, not the
   expectation.
5. WEATHER: is the existing Open-Meteo path usable for CFB outdoor
   stadiums (wind for totals)? Stadium coordinates available from
   the feed?
6. PROPS (R-C): do CFB player prop lines exist at usable coverage,
   and player game stats to resolve them? Measure a real slate.
   Report the evidence; do not build either way.

If any answer kills a market, say so and shrink the build to what
the evidence supports — the probe exists so the build never rests
on hope.

=====================================================================

everything):

=====================================================================
PHASE A — WHAT THE RECORD SAYS ABOUT ITSELF (read-only)
=====================================================================
A1 Law 3 integrity: fingerprint every protected field on every
   prediction; compare against the last stored fingerprint; report
   byte-identical or list every differing row. Run
   foreign_key_check and integrity_check on the live database.
A2 Standing-forecast rules: for every slate, one standing row per
   question per forecaster (latest before start); count rows
   violating it; count superseded rows and confirm none enter
   calibration or any scorecard.
A3 Time truth: any prediction whose created_utc is after its game's
   start; any snapshot before its prediction; any row whose
   league_date disagrees with its kickoff's league day.
A4 The appliance: every scheduled task's last run, result, next
   due from the OS scheduler AND task_runs — list disagreements.
   Confirm the four final passes have fired at least once; confirm
   refresh -> resolve ordering held on every day since installation;
   list MISSED rows and their reasons.
A5 Both forecasters: rows per forecaster per sport since Sep 2;
   any slate where the LLM wrote nothing while the statistical
   wrote rows; llm_calls cost per day against the cap.
A6 Notifications: every row in notifications with its state;
   any 'sending' rows older than an hour (a push that may have
   reached the phone unrecorded).
A7 Secrets: grep the entire git history for any token, key, or
   ntfy topic pattern; confirm .env and the database are ignored
   and absent from every commit; confirm no secret appears in any
   docs/ file or close-out.

=====================================================================
PHASE B — ARE THE GUARDS GUARDING (read-only, then prove)
=====================================================================
B1 Run every planting; then, for the ten most recent plantings,
   RESTORE the fault in a throwaway tree and watch the named
   failure — a guard nobody has seen fail is a guard on faith.
B2 Scanner self-proof: every audit scanner still matches its
   known-positive fixture; every regex in audit.py and plant.py
   compiled and checked for literal backspace bytes or boundary
   anchors that cannot match (the \b lineage, now five deep).
B3 Comment-vs-code: for every scanner that reads source, confirm it
   strips comments and docstrings before matching; plant a comment
   that names the forbidden thing and confirm it does NOT fire.
B4 Duplicated maps: search for any dict/list that declares the
   same domain twice (YES_SIDE, market lists, sport lists, task
   lists, tier maps, verb tables, ladders) — the class behind eight
   past defects. Report every pair; consolidate where one door is
   obvious, list the rest.
B5 Tests that assert nothing: run the suite with --collect-only and
   sample 30 assertions by hand for vacuity (asserting a literal
   they typed, asserting on a fixture that cannot contain the
   shape, skip paths, height-only "reachable" checks). Report each.
B6 Fixtures that make a surface untestable: for every browser
   fixture, list which views render EMPTY in the test world (the
   use_llm=False class) and therefore cannot be scanned.
B7 Gate freshness: confirm verify.py fails INCOMPLETE on an absent
   browser tier, a skipped tier, and captured output; confirm the
   interpreter it runs under is .venv.

C3 DECISIONS_MADE vs code: every ruling that says "enforced by a

   overrule in one sitting.

## How this brief is read

- **Phases A–D are read-only.** Nothing is fixed until Phase E, and Phase E
  fixes only what A–D found and called a clear defect. Anything touching a law,
  a design question, or a tuning temptation is a DECISION in the report.
- **"Verbatim" means verbatim.** The first `verify.py` run is captured to a
  file before anything is touched and reproduced in the report unedited.
- **The report ranks by what it would cost the operator to be wrong about**,
  in the order the brief gives: a wrong record first, an unguarded guard
  second, a misled operator third, a surface fourth, housekeeping last.

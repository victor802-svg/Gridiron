## 1. The closing line, and why the recorded one says nothing

**49 closed recommendations, 49 at exactly 0.00¢, 0 beating the close.** That
is not a measurement. `recommend.record_closing_prices` reads the last
at-the-line claim written before kickoff, and for every recommended
prediction that claim **is the one it was priced from**. Nothing ever writes a
later one:

* the near-start pass (`tasks._near_start_snapshots`) only takes predictions
  whose `open_at_predict` snapshot has an `implied_prob`. **All 55 recommended
  predictions have NULL there**, because the media line never quotes the
  venue's alternate rung. So they never get a second look;
* the venue *does* re-read the same contracts for other predictions of the
  same game, but `at_the_line.evaluate(conn, prediction_ids)` claims only for
  the ids it was handed.

**What the venue's close actually said.** Measured read-only as the same
ticker's last near-start quote before kickoff. It is priced the way the claim
